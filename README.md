I'm a developer building small, practical tools that connect AI agents to real services, and writing
about the work on my blog.

- **MCP servers** — NovelAI-Image-MCP brings NovelAI image generation to MCP clients.
- **Agent skills** — github-api-skill and json-safe-skill give an agent the GitHub API reference and JSON validation rules it needs.
- **Cordis plugins** for DeepSeek Harness — GitHub tools, the Local Dream image backend, `/loop`, and secret handling.
- **NoneBot2 / OneBot 11 bots** — join verification, health alerting, and group administration in real QQ groups.
- **A self-hosted blog** — notes and long-form posts about the same work.
